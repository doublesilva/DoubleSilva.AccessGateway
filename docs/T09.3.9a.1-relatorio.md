## Pré-requisitos (a cumprir antes da instalação)

1. A release com os arquivos da T09.3.6–T09.3.8a implantada em `/srv/accessgateway/app` (a Green atual pode não tê-los;
   implantar a release é uma etapa à parte e precisa de autorização — não faz parte desta tarefa).
2. Docker com acesso à imagem `lldap/lldap@sha256:2a8454b6…` (pull é a única ação de rede; vem de `images.sh`).
3. Janela curta; o Authelia **não** é recriado em nenhum dos passos abaixo.
4. Decidir onde guardar o `KEY_SEED` fora do servidor **antes** de usar (sem ele o banco do LLDAP é inútil).
5. `infra/home-server-backup/backup.conf` novo instalado antes de ligar a cobertura (o checker passa a exigir os itens do
   LLDAP quando `secrets/lldap/KEY_SEED` existir).

## Comandos da futura instalação (root no servidor; não executados)

```bash
cd /srv/accessgateway/app
# 0. estado inicial (somente leitura): backend file e nenhum LLDAP
grep -E '^GATEWAY_AUTH_BACKEND=' /srv/accessgateway/accessgateway.env || echo "(ausente = file)"
docker ps -a --filter name=accessgateway-lldap --format '{{.Names}} {{.Status}}'      # esperado: vazio
# 1. provisionar diretórios e segredos (valores não são exibidos); depois conferir
sudo scripts/lldap-provision.sh
sudo scripts/lldap-provision.sh --check
# 2. guardar o KEY_SEED fora do servidor (decisão do dono; não colar em chat/log) e só então:
# 3. iniciar SOMENTE o LLDAP (perfil lldap; o Authelia não é recriado)
sudo bash -c '. scripts/lib/common.sh; load_env; compose_lldap up -d --wait --wait-timeout 90 lldap'
# 4. verificações
docker inspect -f '{{.State.Health.Status}}' accessgateway-lldap                      # healthy
docker ps --filter name=accessgateway-lldap --format '{{.Ports}}'                      # sem portas publicadas
docker inspect -f '{{.State.StartedAt}}' accessgateway-authelia                        # igual ao registrado no passo 0
sudo scripts/lldap-backup.sh --check-only
sudo scripts/lldap-backup.sh
```

## Reversão da instalação (volta ao estado anterior; o Authelia segue intocado no backend file)

```bash
cd /srv/accessgateway/app
sudo bash -c '. scripts/lib/common.sh; load_env; compose_lldap stop lldap && compose_lldap rm -f lldap'
```
