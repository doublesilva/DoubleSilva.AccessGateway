# T07.5.4 — Documentação de instalação da CA em dispositivos

**Data:** 2026-10-12 · **Branch:** `release/t04-cutover` · **Natureza:** documentação e validação somente leitura.
Nenhum certificado foi instalado, nenhum trust store alterado, e PKI, chaves, containers, DNS, Caddy, Authelia e
firewall continuam intactos. Nada foi distribuído.

**Nenhuma orientação para desabilitar a validação TLS.** O guia proíbe explicitamente ignorar avisos, usar `-k` ou
`verify_ssl: false`. Os casos sem suporte (apps Android que não aceitam CAs do usuário; o core do Home Assistant OS)
são tratados como limitação, a resolver por tarefa específica, nunca contornados.

## 3. Observações e limitações documentadas

| Item | Tratamento |
| --- | --- |
| `cert.home` é HTTP | intencional (bootstrap); a confiança vem do fingerprint conferido por canal confiável |
| Apps Android que não confiam em CAs do usuário | limitação do app; navegadores funcionam |
| Home Assistant OS como cliente HTTPS | sem forma suportada e persistente de adicionar CA ao core; tarefa específica se necessário |
| Rollback para a Blue | mesma raiz, nada muda nos dispositivos; `cert.home` indisponível (404) durante o rollback |
| Rotação (até 07/2035) | sobreposição: instalar a nova raiz ao lado da antiga, trocar no servidor, remover a antiga depois da observação |
| Comprometimento | remoção imediata por plataforma (§10) e rotação de emergência |
| Menus por versão | os caminhos são os mais comuns; os comandos de linha valem entre versões |

## 4. Reversão

Documentação apenas. Para reverter, basta remover os dois arquivos do repositório. Nada foi aplicado em produção.
