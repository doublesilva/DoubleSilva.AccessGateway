## 6. Reversão

Rota, imediata e sem restart:

```sh
sudo /srv/accessgateway/app/scripts/caddy-reload.sh --revert /srv/accessgateway/logs/caddy-config-20261011T145050.json
```

Para tornar a reversão permanente (um restart futuro do Caddy releria os arquivos novos), restaure `caddy/` da release
anterior (`4368be6`): `sites/doublesilva.caddy` sem o `import status_dashboard` e `snippets/status-dashboard.caddy`
removido. Depois rode `caddy-reload.sh --check`, que deve indicar configuração idêntica.

Sincronização:

```sh
sudo bash /srv/accessgateway/app/infra/accessgateway-status-sync/install.sh --revert   # units, script e status/
```

Nenhum passo de reversão reinicia containers ou altera o smoke, o publicador ou o timer.
